# Contributing

Thanks for your interest. This project is intentionally small, local-first, and safety-oriented.

## Good contributions

- Improve schemas, fixtures, validators, and documentation.
- Add examples that use synthetic or public-safe data only.
- Add tests for boundary cases, malformed packets, missing citations, and unsafe autonomy.
- Keep network calls optional and disabled by default.

## Boundaries

- Do not add secrets, credentials, private source material, student data, customer data, or account automation.
- Do not add auto-publishing, auto-emailing, account login, payment, KYC, or external side effects.
- Prefer Python standard library and deterministic fixtures unless a dependency is clearly justified.
