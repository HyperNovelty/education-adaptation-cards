# Security Policy

This repository contains local-only education adaptation card fixtures, a small
validator, and a deterministic markdown renderer. It is intended for review of
synthetic examples only.

## No Student Data

Do not submit student records, grades, private learner profiles, classroom rosters,
LMS exports, parent/guardian information, assessment records, credentials, tokens,
or account material in issues, pull requests, fixtures, examples, or rendered
dossiers.

Fixtures should use synthetic or public-safe data only.

## No Runtime or Classroom Authority

Artifacts in this repository do not authorize:

- classroom deployment
- grading or learner evaluation
- student-data collection
- LMS, school, or account integration
- public publishing or distribution
- compliance, legal, accessibility, privacy, or curriculum approval claims

All outputs are local review materials until separately reviewed and approved
outside this prototype.

## Reporting a Vulnerability

Report suspected security issues privately through the repository owner's
published security contact or normal maintainer process. Do not include private
student data, credentials, or real account material in the report.
